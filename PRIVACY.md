# Privacy

Blake Labs Guitar Tuner is designed to work without collecting user data.

## Microphone

The app requests Android's `RECORD_AUDIO` permission solely to analyze pitch in real time.

Microphone samples are:

- processed locally on the device;
- held temporarily in memory;
- not written to a recording file;
- not uploaded;
- not shared with Blake Labs or third parties.

## Network

The application does **not** request the Android Internet permission.

## Tracking and advertising

There are no advertising SDKs, analytics SDKs, telemetry SDKs, account systems, fingerprinting systems or "growth" surprises in the current application.

If that ever changes, this document and the changelog must change before the code ships.
